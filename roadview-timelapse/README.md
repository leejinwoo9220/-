# 로드뷰 도시 변화 타임랩스 (rvt)

같은 장소를 연도별로 캡처한 로드뷰 3~5장(보통 2008~2009년부터 현재까지)을 받아 아래 순서로 처리합니다.

1. **어안 제거**: 로드뷰 뷰어 특유의 휘어진 화면을 일반 사진(직선이 곧은 사진)으로 펴기
2. **같은 화각·구도로 정렬**: 모든 연도를 기준 연도 한 장의 시점에 픽셀 단위로 맞추기
3. **영상 생성(Sogni, MiniMax H3 Standard)**: 캡처 날짜에서는 실제 속도로, 그 사이 기간은 빨리감기 타임랩스로
4. **후반 보정**: 간판 글자를 원본 픽셀로 고정하고, 멈춰 있는 사람/차를 검출·제거하고, 속도 램프를 적용한 뒤 합본

기획 기준은 노션 「로드뷰 도시 변화 타임랩스」(source-only-v1-final)를 따릅니다. 실제 연도별 로드뷰를 같은 시점으로 정렬하고, 간판·업종·노후·공사 변화를 보존하며, 디졸브나 녹아내리는 morph, 가짜 간판, 화면 연도 텍스트는 쓰지 않습니다.

```bash
cd roadview-timelapse
pip install -r requirements.txt          # numpy, opencv-contrib, pillow, pytest
# ffmpeg / ffprobe 가 PATH 에 있어야 합니다 (Mac: brew install ffmpeg, Windows: winget install ffmpeg)

# 영상 생성용 Sogni CLI (Node 22 이상)
npm i -g @sogni-ai/sogni-creative-agent-skill@3.55.0
sogni-agent doctor --json                # "success": true 확인
export SOGNI_API_KEY=...                 # 또는 ~/.config/sogni/credentials (저장소에는 절대 넣지 않음)
```

Windows에서는 `sogni-agent.cmd`가 cmd.exe를 거치면서 여러 줄로 된 H3 프롬프트가 깨질 수 있습니다. 그래서 `rvt`가 `npm root -g` 아래의 `sogni-agent.mjs`를 찾아 `node`로 직접 실행합니다. 경로를 직접 지정하려면 `SOGNI_AGENT` 환경 변수를 쓰세요.

키나 캡처 원본은 이 공개 저장소에 올리지 않습니다(`.gitignore`에서 `captures/`와 `work/`를 제외합니다).

## 작업 순서

### 0) 캡처 준비

- 같은 지점에서 카카오맵이나 네이버 지도의 과거 로드뷰를 날짜별로 캡처합니다. 방향과 확대 정도는 최대한 같게 맞춥니다.
- 원본은 PNG로, 해상도는 높게 저장합니다(레티나 화면 그대로). 간판 글자 화질이 최종 영상의 간판 화질을 결정합니다.
- 화면 가장자리에 여유를 두세요. 정렬 후 모든 연도에 공통으로 보이는 영역만 잘라 쓰기 때문입니다.
- 뷰어 UI(버튼, 미니맵, 날짜 표시)는 `crop`으로 잘라내거나, 화면 안에 겹친 UI는 `ignore` 영역으로 지정합니다.
- 로드뷰 이미지의 사용·배포 권리는 별도로 확인해야 합니다(기획 원장의 blocker 항목).

### 1) `project.json` 작성

`examples/project.example.json`을 복사해서 씁니다.

| 키 | 의미 |
|---|---|
| `captures[].crop` | 원본 캡처에서 로드뷰 화면(viewport)만 남길 `[x, y, w, h]`. 어안 중심은 이 영역의 중앙으로 계산합니다 |
| `captures[].ignore` | 특징점 매칭에서 제외할 영역(화면 위 UI, 워터마크) |
| `captures[].undistort` | 기본값 `{"model": "auto"}`. 고정하려면 `{"model": "division", "param": -0.22}`, 어안 모델은 `stereographic` / `equidistant` / `equisolid` |
| `captures[].anchors` | 자동 매칭이 실패할 때 수동 대응점 4개 이상 `[x, y, x_ref, y_ref]`(`work/undistorted/*_grid.jpg`의 픽셀 좌표) |
| `captures[].crowd` | `light` / `moderate` / `busy`. 실제 속도 구간의 인파 밀도 |
| `reference` | 구도의 기준이 될 캡처(기본값은 가장 최근 캡처) |
| `scene` | 영어로 쓴 장면 한 줄 묘사(H3 프롬프트에 들어감) |
| `transitions["A>B"].changes` | 두 시점 사이에 실제로 바뀐 것만 영어로 적습니다(없는 공사 이력을 지어내지 않음) |
| `signs[].box` | 간판 위치 `[x, y, w, h]`(0~1 정규화). `work/qa/sign_grid.jpg`의 격자를 보고 읽습니다 |
| `orientation` | `landscape`(H3 캔버스 1344×768, 납품 1920×1080) 또는 `portrait`(768×1344, 납품 1080×1920) |

### 2) 정지 이미지: 어안 제거와 정렬

```bash
python -m rvt prep project.json
```

| 결과 | 내용 |
|---|---|
| `work/undistorted/<id>.jpg` | 어안을 제거한 일반 사진 |
| `work/aligned/master/<id>.png` | 같은 화각·구도로 맞춘 고해상도 사진(간판 고정에 사용) |
| `work/aligned/canvas/<id>.png` | H3 입력 크기(1344×768)로 맞춘 사진 |
| `work/qa/stills_sheet.jpg`, `blink.gif` | 연도별 비교 시트와 깜빡이 비교 |
| `work/qa/edges_<id>.jpg` | 기준 윤곽선(마젠타)을 겹친 이미지. 선이 이중으로 보이면 정렬이 어긋난 것 |
| `work/prep.json` | 렌즈 계수, 호모그래피, 매칭 경로, 잔여 오차(`residual_flow_vs_reference`) |

### 3) 영상 생성 계획과 실행 (Sogni, MiniMax H3 Standard)

```bash
python -m rvt plan project.json               # 프롬프트와 명령만 생성(비용 없음)
python -m rvt generate project.json           # dry-run: 실행할 sogni-agent 명령 출력
python -m rvt generate project.json --execute # 실제 생성(홀드 → 전환 순서, 이미 받은 클립은 건너뜀)
```

- 모델 선택자: 홀드는 `minimax-h3-i2v`, 전환은 `minimax-h3-flf2v`(Standard, 20 step, 24fps, 1344×768)를 씁니다.
- `--no-expand-prompt`로 CLI의 프롬프트 자동 재작성을 끄고, H3 공식 3필드 계약(정렬 첫 줄, `integrated_multimodal_description`, `overall_soundscape`, `non_diegetic_music`)을 그대로 보냅니다.
- `--billing-mode subscription`: Unlimited로 처리할 수 없는 작업은 Spark로 넘기지 않고 거절(4078/4080)됩니다.
- 생성 로그(시작 시각, 소요 시간, 결과)는 `work/clips/generation_log.json`에 남습니다. 실패 시 무작정 재전송하지 말고 `sogni-agent --recent --json`부터 확인하세요.
- Sogni 웹에서 직접 생성해도 됩니다. `work/prompts/*.txt`의 프롬프트와 `plan.json`의 입력 이미지를 쓰고, 결과를 `work/clips/<세그먼트>.mp4`로 저장하면 됩니다. 전환의 첫 프레임은 홀드를 받은 뒤 `python -m rvt seam project.json hold_<id>`로 만들어진 `work/seams/<id>_end.png`입니다.
- 비용: 생성 초 × 16 Spark(Standard 768p, 1 Spark = $0.005). 5장 기준 약 50~58초, Unlimited 미적용 시 약 800~950 Spark입니다.

### 4) 후반 보정과 합본

```bash
python -m rvt finish project.json   # → work/final/<name>.mp4, work/qa/finish_report.json
```

## 영상 구조

```
[2009 실제속도] → [2009→2014 타임랩스] → [2014 실제속도] → … → [2026 실제속도]
  HOLD (I2V)        TRANS (FLF2V)           HOLD (I2V)               HOLD (I2V)
  K₂₀₀₉에서 시작    E₂₀₀₉ → K₂₀₁₄           K₂₀₁₄에서 시작
```

- `K`: 정렬된 캡처 원본, `E`: 홀드에서 실제로 보여 준 마지막 프레임(간판 고정 적용 후)
- 전환 클립의 첫 프레임은 바로 앞 홀드의 실제 마지막 프레임이고, 마지막 프레임은 다음 홀드의 첫 프레임(원본 캡처)입니다. 그래서 모든 이음새가 정확히 맞습니다.
- 기본 길이: 홀드 3초(마지막 홀드 4초), 전환 2.6초. 5장이면 약 25초입니다.

## 가장 흔한 오류 "건물·간판은 바뀌는데 사람·차는 멈춰 있음" 대책

원인은 첫/끝 프레임 방식(FLF2V)에서 두 기준 프레임 속 사람을 모델이 "계속 있어야 하는 피사체"로 붙잡아 두고 배경만 morph하는 데 있습니다.

1. **속도를 모델에 맡기지 않습니다.** 실제 속도의 움직임은 홀드(I2V) 클립만 만들고, 빨리감기는 후반에서 결정론적으로 처리합니다(셔터 블렌딩 리타임: 1배속 → 최대 3~5배속 → 1배속).
2. **프롬프트에서 사람의 퇴장과 등장을 시간대로 지정합니다.** 기준 프레임의 사람은 첫 1초 안에 화면 밖으로 나가고, 중간은 아주 짧게 스치는 모션블러 행인과 차량 흐름으로 채우며, 마지막 1초에 Picture 2의 사람들이 걸어 들어옵니다(H3 공식 문법: 부정어 대신 긍정 묘사).
3. **빨리감기 구간의 잔상은 실제 셔터처럼 만듭니다.** 빨라질수록 여러 프레임을 평균해 행인이 잔상으로 흐르고, 양 끝 1배속 구간에는 블러가 없습니다.
4. **멈춘 사람을 검출하고 제거합니다.** 홀드 클립에서 누가 기준 프레임에 있었는지(움직임 마스크) 알 수 있습니다. 그 사람이 전환 중에 유예 시간(0.75초)이 지나도 같은 자리에 있으면 `start_subject_frozen`, 다음 시점의 사람이 너무 일찍 와서 서 있으면 `end_subject_frozen`으로 기록하고, 홀드에서 구한 거리 배경(시간축 중앙값)으로 페이드 교체합니다(`finish.fix_frozen`, 기본값 켜짐). 검출 위치는 `work/qa/frozen_<전환>.jpg`에 표시됩니다.
5. **홀드 자체가 정지 화면이면 경고합니다.** 움직임 면적이 0.3% 미만이면 `finish_report.json`에 재생성 권고를 남깁니다.

## 간판 텍스트를 최대한 정확하게: 적용한 방법

영상 모델은 모든 프레임의 모든 픽셀을 다시 그리기 때문에 간판 글자가 흔들리거나 녹거나 가짜 글자가 됩니다. 이 영상은 카메라가 고정이므로 **움직이지 않는 픽셀은 모델이 그린 것 대신 실제 캡처 원본으로 되돌릴 수 있습니다.**

1. **움직임 마스크 합성(홀드)**: 사람, 차, 그림자처럼 움직이는 곳만 생성 픽셀을 쓰고 나머지는 정렬된 원본 캡처를 씁니다. 간판 글자는 캡처 원본과 같아집니다. 합성 데모에서 간판 영역 PSNR이 24.6dB에서 36dB로 올랐습니다(남은 차이는 H.264 압축).
2. **원본 해상도로 합성**: H3는 768p로 출력하지만, 간판은 고해상도 정렬 캡처(`aligned/master`)에서 가져와 1080p로 납품합니다.
3. **간판 팝-스왑(전환)**: `signs` 박스 안은 모델이 그린 중간 글자를 쓰지 않습니다. 옛 간판 원본을 보여 주다가, 모델의 간판이 새 간판에 더 가까워지는 순간 새 간판 원본으로 한 번에 바꿉니다. 실제 타임랩스처럼 끊어서 바뀌고 녹는 morph나 가짜 중간 글자가 없습니다. 바뀌지 않은 간판은 처음부터 끝까지 고정합니다.
4. **가림 판별**: 간판 상자 안에서만 생긴 변화는 글자를 다시 그린 것으로 보고 무시합니다. 상자 밖까지 이어지면서 프레임마다 움직이는 물체(버스, 행인)만 간판 앞을 지나가게 둡니다.
5. **이음새 착지 고정**: 전환의 처음과 끝 8프레임은 원본 캡처로 점점 고정되어, 각 시점이 정확한 원본 사진에 착지합니다.
6. **프롬프트에 글자를 쓰게 하지 않습니다.** 간판 내용은 언급하지 않고 "새 간판이 통째로 선명하게 나타난다"는 사건만 묘사합니다. 글자는 후반에서 원본으로 채웁니다.

추가로 쓸 수 있는 방법(아직 미구현):

- **OCR 검수**: 한국어 OCR(PaddleOCR, EasyOCR)로 출력 프레임의 간판을 읽어 원본 캡처와 비교하면 자동으로 판정할 수 있습니다.
- **생성 클립 업스케일**: 사람·차 영역의 화질이 아쉬우면 Sogni FlashVSR(`sogni-agent --upscale-video`)로 업스케일한 뒤 같은 고정 과정을 거칩니다. 간판에는 생성형 초해상도를 쓰지 않습니다(글자를 지어낼 위험).
- **LoRA**: `video.loras`에 `{"id": "h3-realism-people", "strength": 0.6}`를 넣으면 사람 질감이 좋아집니다. 강도 1.5 이상에서는 카메라가 당겨져 구도가 깨질 수 있습니다. 프롬프트 준수용 `h3-vbvr-video-reasoning`은 Sogni에서 `--no-filter`를 요구하므로 기본값에서 뺐습니다.

## 어안 제거 방식

- 뷰포트 중심 기준의 방사 왜곡으로 모델링합니다. 기본값은 1-파라미터 division 모델(`r_u = r_d / (1 + λ r_d²)`)이고, 진짜 어안 투영(등거리, 입체, 등입체각)도 지원합니다.
- 계수는 plumb-line 기준으로 자동 추정합니다. 왜곡된 화면에서 짧은 선분을 찾아 후보 계수마다 편 다음 Hough 공간에 투표하고, 같은 건물 모서리의 조각들이 한 직선에 가장 잘 모이는 계수를 고릅니다. 합성 데이터에서 λ 오차는 ±0.01~0.02 수준입니다.
- 결과는 테두리에 빈 픽셀이 생기지 않는 최대 내접 사각형으로 자르고, 정렬 렌더링에서는 원본 캡처에서 한 번만 리샘플링합니다(왜곡 보정, 정렬, 크롭을 하나의 맵으로 합성).

## 정렬 방식

- RootSIFT 특징점, 상호 일치와 비율 테스트, MAGSAC 호모그래피를 씁니다. 지나가는 사람과 차는 이상치로 빠집니다.
- 2009년과 2026년처럼 공통점이 적은 쌍은 매칭 그래프의 최대 병목 경로(예: 2009 → 2014 → 2019 → 2026)로 연결합니다.
- 기준 사진과 다시 직접 대조하는 2차 정밀 정합을 거칩니다(공간 창 30px, 임계 2px).
- 모든 연도의 공통 영역에서 목표 화면비의 최대 사각형을 잘라 냅니다. 가장자리를 지어내지 않습니다.
- 톤 보정은 기준 연도 쪽으로 밝기만 35% 당깁니다. 연도별 카메라 색감도 시대 정보이므로 색은 기본적으로 유지합니다.

## 한계

- 실제 H3 출력으로는 아직 검증하지 않았습니다. 합성 데이터와 가짜 클립으로 검증했으므로 첫 실데이터에서 `lock_threshold`, `sign_threshold`, `frozen_grace_seconds` 조정이 필요할 수 있습니다.
- 호모그래피 정렬은 주된 건물 면(평면)을 기준으로 맞춥니다. 촬영 위치 차이가 수 미터 이상이면 가까운 물체(전봇대 등)에 시차가 남습니다. 이때는 수동 대응점을 건물 면에 찍어 주세요.
- 간판 박스는 사람이 지정해야 합니다(`sign_grid.jpg` 참고).
